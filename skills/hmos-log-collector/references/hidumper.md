# Hidumper Collection

Use `hidumper` for non-destructive device and process snapshots. Prefer bounded,
read-only queries and record each command individually.

Useful evidence includes device/system information, process details, memory,
thread/stack summaries, and window/ability state for UI failures. Availability
and privileges vary by build. Preserve permission failures while continuing
independent collection. Do not reboot, kill apps, clear logs, or change settings
without explicit approval.
